1. Executive Summary

The Iced Tea House Business Operating System is a cloud-based, centralized platform that connects every aspect of the business — from taking an order to tracking inventory, managing purchases, recording expenses, and viewing financial reports.

One transaction updates everything automatically. When an order is placed, inventory is tracked, revenue is recorded, profit is calculated, reports are updated, and an audit trail is logged — all instantly.

The system is accessible from any device with a browser — desktop, tablet, or phone — and all users share the same live data.

5. PR / Complimentary Orders

The system has a dedicated workflow for PR (public relations) or complimentary drinks:

┌─────────────────────────────────────────┐ │ User toggles [PR / Comp] button │ │ │ │ ✓ Purple indicator appears │ │ ✓ Total forced to FREE │ │ ✓ Payment forced to PAID │ │ ✓ Status forced to COMPLETED │ │ │ │ WHAT STILL HAPPENS: │ │ ✓ Inventory is deducted (tracked) │ │ ✓ Order appears in records │ │ ✓ Item counts toward product stats │ │ │ │ WHAT IS EXCLUDED: │ │ ✗ Revenue NOT recorded │ │ ✗ Does NOT affect financial reports │ │ ✗ Shows as PR in all views │ └─────────────────────────────────────────┘

Result: PR drinks appear in order records and inventory tracking but are clearly separated from paid revenue in all reports.

6. Card / POS Payment Charges

When a customer pays by card, the system automatically adds a processing fee:

ComponentExample
SubtotalPKR 1,000
Card fee (2.5%)PKR 25
Total chargedPKR 1,025

The fee percentage is configurable in Settings → Payment & Expenses. It can be changed anytime if the bank or payment provider changes its charges.
